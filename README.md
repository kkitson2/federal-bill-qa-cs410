# federal-bill-qa-cs410
Ask questions about federal bills and get ranked sections, passages and citations back. BM25 + semantic search + RRF, built on Congress.gov and GovInfo data.

## How the work fits together

- **Group 1:** Prepared the bill data and test questions.
- **Group 2:** Built the search backend that returns ranked bill sections, text, and citations.
- **Group 3:** Build the interface for asking questions and viewing results. Add AI-generated answers grounded in the retrieved sections, with citations. Test the complete application and check that the cited passages support its answers.

Group 3 can choose its own tools and design. Start with the [search setup and usage guide](search/README.md) to connect to the existing backend.
